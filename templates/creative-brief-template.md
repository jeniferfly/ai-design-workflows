# Creative Brief Template

A reusable starting point for design, presentation, UX, interactive, and
AI-assisted creative work.

Use only the sections that improve the project. A brief should create
clarity---not paperwork.

## AI-Assisted Work

When AI is part of the workflow:

-   provide only appropriate source material;
-   use the current source of truth;
-   make constraints explicit;
-   surface unresolved decisions;
-   review all generated output;
-   preserve approved work during targeted revisions.

------------------------------------------------------------------------

## Guiding Principle

**A good brief gives creativity direction without prescribing every
decision.**
