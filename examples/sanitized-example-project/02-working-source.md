# 02 --- Working Source

This is the clean Markdown source prepared for the design task.

## Goal

Create a responsive Creative Project Dashboard for small creative teams.

## Audience

Designers and creative leads.

## User Needs

Users need to quickly understand:

-   today's three priority tasks;
-   active projects;
-   current project status;
-   the next important action.

## Required Content

### Today's Priorities

Show exactly three priority tasks.

### Active Projects

Show a small list of active projects.

Each project must include:

-   project name;
-   concise status.

### Primary Action

Include one clearly identifiable primary action.

## Visual Direction

-   clean;
-   calm;
-   spacious;
-   focused;
-   intentional;
-   minimal decoration.

## Accessibility

-   maintain readable contrast;
-   maintain clear hierarchy;
-   do not rely on color alone to communicate status;
-   include visible focus treatment in interactive concepts.

## Responsive Consideration

The hierarchy should remain understandable on desktop and mobile.

## Open Decision

The source does not establish whether project status should use progress
bars or text labels.

Do not silently treat either approach as a requirement.

## Deliverable

Review-ready design concept with a short rationale.
