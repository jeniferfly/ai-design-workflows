# Sanitized Example Project

This fictional example demonstrates how the AI Design Workflows system
can move from a creative brief to a controlled revision and approved
baseline.

No client, employer, proprietary, or confidential material is used.

## Scenario

A fictional product team needs a simple **Creative Project Dashboard**
for small design teams.

The dashboard should help a user quickly understand:

-   today's priorities;
-   active projects;
-   current project status;
-   the next important action.

The project is intentionally small so the workflow is easy to follow.

------------------------------------------------------------------------

## Example Flow

**01 Creative Brief → 02 Working Source → 03 Design Request → 04
Revision Request → 05 Approved Baseline → 06 Reusable Learning**

### 01 --- Creative Brief

Defines the problem, audience, requirements, visual direction, and
success criteria.

See [`01-creative-brief.md`](01-creative-brief.md).

### 02 --- Working Source

A clean Markdown handoff containing only the context needed for the
design task.

See [`02-working-source.md`](02-working-source.md).

### 03 --- Design Request

Turns the source into an explicit AI-assisted design request.

See [`03-design-request.md`](03-design-request.md).

### 04 --- Targeted Revision

Demonstrates how feedback can change one visual relationship while
protecting the approved parts of the concept.

See [`04-targeted-revision.md`](04-targeted-revision.md).

### 05 --- Approved Baseline

Records what has been approved so the next revision starts from a known
state.

See [`05-approved-baseline.md`](05-approved-baseline.md).

### 06 --- Reusable Learning

Captures only the lessons worth carrying into future work.

See [`06-reusable-learning.md`](06-reusable-learning.md).

------------------------------------------------------------------------

## What This Example Demonstrates

The important part is not the fictional dashboard.

It is the workflow around it:

-   clean source preparation;
-   explicit requirements;
-   visible open decisions;
-   human review;
-   targeted revision;
-   protected baselines;
-   selective learning.

------------------------------------------------------------------------

## Guiding Principle

**AI sits inside the creative process. It is not the process itself.**
