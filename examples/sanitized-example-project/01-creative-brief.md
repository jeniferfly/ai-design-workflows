# 01 --- Creative Brief

## Project

**Project name:** Creative Project Dashboard\
**Project type:** Responsive dashboard concept\
**Status:** Exploration

------------------------------------------------------------------------

## Purpose

Create a simple dashboard concept that helps a small creative team
understand today's work without opening several project views.

The experience should make priorities and project status easy to scan.

------------------------------------------------------------------------

## Audience

Designers and creative leads managing a small number of active projects.

They need to quickly answer:

-   What needs my attention today?
-   Which projects are active?
-   What is the current status?
-   What should I do next?

------------------------------------------------------------------------

## Core Message

> **See what matters today without sorting through everything.**

------------------------------------------------------------------------

## Requirements

The concept must include:

-   three priority tasks for today;
-   a list of active projects;
-   a visible status for each project;
-   one clear primary action;
-   desktop and mobile consideration;
-   accessible visual hierarchy.

------------------------------------------------------------------------

## Visual Direction

The experience should feel:

-   clean;
-   calm;
-   spacious;
-   focused;
-   intentional.

Avoid excessive decoration, heavy shadows, and unnecessary dashboard
density.

------------------------------------------------------------------------

## Open Decision

The brief does not establish whether project status should be
represented with progress bars or concise text labels.

This should remain an open design decision until reviewed.

------------------------------------------------------------------------

## Success Criteria

The concept succeeds when a user can quickly identify:

1.  today's priorities;
2.  active project status;
3.  the primary next action.

No additional product functionality is required for this exercise.
