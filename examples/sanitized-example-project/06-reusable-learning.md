# 06 --- Reusable Learning

Not every project detail needs to become permanent guidance.

This example produced three lessons worth carrying forward.

------------------------------------------------------------------------

## 1. Use Spacing Before Adding Decoration

When two sections need clearer separation, first evaluate whether
spacing and hierarchy can solve the problem before adding dividers,
panels, borders, or other visual elements.

**Potential reuse:** Visual design principle.

------------------------------------------------------------------------

## 2. Keep Unresolved Decisions Visible

The project-status treatment was not established by the source.

Keeping that decision open prevented an exploratory choice from becoming
an accidental requirement.

**Potential reuse:** Source-of-truth and decision-making pattern.

------------------------------------------------------------------------

## 3. Protect Approved Relationships During Revision

The targeted revision changed one relationship---the space between two
sections---while preserving card dimensions, typography, content, and
interaction hierarchy.

**Potential reuse:** Targeted revision pattern.

------------------------------------------------------------------------

## What We Did Not Preserve

The fictional dashboard content itself is not a reusable standard.

The specific task names, project names, and example layout belong only
to this example.

------------------------------------------------------------------------

## Guiding Principle

**Capture the lesson---not every detail of the project.**
