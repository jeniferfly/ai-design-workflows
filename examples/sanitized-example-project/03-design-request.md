# 03 --- Design Request

## Context

Create a concept for a fictional Creative Project Dashboard used by
small creative teams.

## Source

Use `02-working-source.md` as the authoritative content source.

## Goal

Help users understand today's priorities and active project status at a
glance.

## Requirements

-   Show exactly three priority tasks.
-   Show active projects with concise status.
-   Include one clear primary action.
-   Maintain clear hierarchy on desktop and mobile.
-   Preserve the accessibility requirements in the source.

## Visual Direction

Create a clean, calm, spacious interface with strong hierarchy and
minimal decoration.

Prioritize clarity over dashboard density.

## Constraints

Do not introduce product features that are not established by the
source.

## Open Decision

The source does not establish whether project status should use progress
bars or text labels.

Treat this as a design decision for review rather than silently
establishing a requirement.

## Verification

Confirm that:

-   all required content is represented;
-   today's priorities are visually prominent;
-   the primary action is clear;
-   status does not rely on color alone;
-   no unsupported functionality has been introduced.

## Deliverable

Review-ready design concept with a short design rationale.
